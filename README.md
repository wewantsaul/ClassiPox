# ClassiPox
under development. working only for ont-artic

## working command
``` nextflow run ClassiPox --inDir <input_directory> --samplesheet <samplesheet.csv> --nanoporeArtic --outdir <output_directory> ``` \
notes: \
```--samplesheet``` is optional \
``` --inDir ``` should be the fastq_pass (raw barcode seq), not concatenated fastq. other input types still under devs \
``` nextflow run ClassiPox --help ``` for more details
